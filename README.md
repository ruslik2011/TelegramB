# TelegramBot
# Хранитель музыки

Телеграм-бот, который хранит мою музыку. Кидаешь ему mp3 или mp4 — он сохраняет трек в библиотеку, а потом по команде находит и присылает обратно.

## Зачем я это сделал

У меня музыка валяется везде: в избранном, в чатах, на флешке, в старых папках. Найти нужный трек через полгода — целый квест. Облачные хранилища платные, а места на телефоне вечно нет.

В итоге сделал бота, который всегда под рукой, потому что Телеграм и так открыт. Файлы никуда не качаются — бот просто запоминает ссылку на файл, которая уже лежит на серверах Телеграма. Поэтому он ничего не жрёт и работает бесплатно.

## Что умеет

- принимает аудио, видео и медиа-файлы (mp3, mp4, m4a, ogg, wav, flac)
- не сохраняет один и тот же файл дважды
- ищет по названию, исполнителю или имени файла
- показывает сколько всего треков
- кидает последние добавленные или случайный трек
- кнопки под сообщением, чтобы не писать команды руками
- у каждого пользователя своя отдельная библиотека
